# Atlassian AI Agent Registry

A one-page template for tracking custom Rovo agents so they don't sprawl.

## Why

Custom agents are easy to create. A few months in, teams often can't say
how many exist, who owns them, or what they can read. A registry answers
those questions in one place.

## Registry template

| Agent name | Owner (a named person) | Purpose (one sentence) | What it can read (spaces/projects) | Used in (chat / automation rule) | Last reviewed | Retire if... |
|---|---|---|---|---|---|---|
| | | | | | | |

## Before creating a new agent

- [ ] Does an existing agent already cover this?
- [ ] Is there a named owner, a person rather than a team?
- [ ] Which spaces and projects can it read, and is that intentional?
- [ ] Will it run inside an automation rule that could act unattended?
- [ ] Is a review date set?

## Retiring agents

If nobody can name the owner or the last time it was used, archive it.
